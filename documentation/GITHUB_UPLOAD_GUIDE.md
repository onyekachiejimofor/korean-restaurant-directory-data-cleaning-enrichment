# Upload this portfolio to GitHub — no command line required

## Recommended repository name
`korean-restaurant-directory-data-cleaning-enrichment`

## Suggested one-line GitHub description
`Real-world NYC & LA Korean restaurant directory: Excel/Power Query cleaning, manual web research, contact enrichment and QA (488 records).`

## Recommended method: GitHub Desktop
1. Download the ZIP file for this project, then **extract** it. Do not upload the ZIP as the only file in the repository — GitHub would not display the README and directory structure properly.
2. Launch GitHub Desktop (sign in to your GitHub account).
3. Choose **File > Add Local Repository > Choose**, select the extracted `korean_restaurant_directory_portfolio` folder. If GitHub Desktop offers **Create a repository here**, choose that option.
4. For the repository name, use `korean-restaurant-directory-data-cleaning-enrichment`. Add an optional short description.
5. Review the changed files, enter commit summary `Initial portfolio case study: Korean restaurant directory`, and commit.
6. Click **Publish repository**, select public only if you are comfortable with publishing these business contacts and have checked data-source reuse requirements.
7. Open the repository page in a browser: `README.md` should appear automatically on the homepage.

## Browser-only alternative
Create an empty repository on GitHub. From its **Add file > Upload files** screen, drag the contents of the extracted project folder (where folder upload is supported), confirm the nested paths, then commit. If folders fail to upload, GitHub Desktop is safer for this multi-folder project.
